# Veli 사용 안내

파일을 서버에 업로드하지 않고 브라우저에서 암호화하거나 복호화해요. 가입이나 계정이 필요하지 않아요.

<h2 id="project-history">프로젝트의 시작</h2>

Veli는 mrtechtroid가 관리하던 [Hatsmith](https://github.com/mrtechtroid/hatsmith)를 계승한 프로젝트예요. Hatsmith는 sh-dv와 기여자들이 만든 [hat.sh](https://github.com/sh-dv/hat.sh)에서 시작했어요. Veli는 두 프로젝트의 암호화 구현과 v2 파일 형식을 이어받아 화면과 사용 경험을 개선해요. 원본의 저작권과 기여자 표기도 유지해요.

## 파일 보호하기

1. **파일 암호화**에서 보호할 파일을 선택해요. 원본 파일은 그대로 유지돼요.
2. 파일을 다시 열 때 사용할 비밀번호를 12자 이상 입력해요. **비밀번호 만들기**에서 무작위 문자나 단어 조합을 만들 수도 있어요.
3. 비밀번호를 안전한 곳에 보관하고 **암호화 준비하기**를 눌러요. 비밀번호를 잊어버리면 복구할 수 없어요.
4. 파일과 방식을 확인하고 암호화해요. 데스크톱의 스트리밍 방식은 처리와 다운로드가 함께 시작돼요. 한 파일 방식은 처리가 끝난 뒤 **암호화 파일 다운로드**를 눌러주세요.
5. 브라우저의 다운로드 목록에서 파일이 저장됐는지 확인해요.

파일을 공유한다면 비밀번호는 다른 경로로 전달하는 것을 권장해요. 이 앱이 파일이나 비밀번호를 대신 전송하지는 않아요.

## 파일 다시 열기

1. **파일 복호화**에서 받은 암호화 파일을 선택하고 **파일 확인하기**를 눌러요.
2. 암호화할 때 사용한 비밀번호를 입력해요. 공개키 방식의 파일이면 보낸 사람의 공개키와 내 개인키를 입력해요.
3. 안내에 따라 파일을 복호화하고 다운로드해요.
4. 다운로드 목록에서 저장된 파일을 확인해요.

전체 파일 검증에 실패하면 완료 안내가 나오지 않아요. 스트리밍 도중 오류가 발생하면 일부 파일이 다운로드됐을 수 있으니 삭제하고 원본 암호화 파일로 다시 시도해주세요.

## 공개키 사용하기

비밀번호 설정 단계의 **공개키로 암호화하기 · 고급**에서 사용할 수 있어요.

- 암호화: 받는 사람의 공개키와 내 개인키가 필요해요.
- 복호화: 보낸 사람의 공개키와 받는 사람 자신의 개인키가 필요해요.
- 공개키는 상대방에게 공유해도 돼요. 개인키는 다른 사람에게 보내지 마세요.
- 키가 없다면 **키 만들기**를 이용하거나 [키 생성 화면](/generate-keys/)을 열어주세요. 생성된 개인키를 다운로드하고 안전하게 백업해두세요.
- 공개키 QR 코드와 링크에는 공개키만 담겨요. 암호화 파일은 별도로 전달해주세요.
- 새 키 쌍은 이전 개인키를 대체하지 못해요. 이전 키로 암호화된 파일을 열려면 그 개인키가 필요해요.

## 브라우저와 파일 크기

Safari와 모바일, 스트리밍을 사용할 수 없는 환경에서는 파일을 하나씩 처리해요. 입력 상한은 1 GiB이며 기기 메모리에 따라 더 작은 파일이 필요할 수 있어요. iPhone과 iPad에서는 작은 파일부터 시작하는 것을 권장해요.

파일 정보의 해시는 메모리 사용을 줄이기 위해 32 MiB 이하 파일에만 계산해요. 큰 파일도 파일명과 크기를 확인할 수 있어요.

파일 처리가 끝날 때까지 페이지를 열어두세요. 브라우저가 저장을 담당하므로 앱의 처리 완료 안내만으로 기기 저장이 확인되는 것은 아니에요.

## 오류가 생겼을 때

- 파일을 열 수 없다면 비밀번호나 키를 확인해주세요. 계속 실패하면 보낸 사람에게 암호화 파일을 다시 받아주세요.
- 지원하지 않는 형식이라면 지원하는 v2 형식으로 만든 파일인지 확인해주세요. 이전 v1 형식은 현재 앱에서 열 수 없어요.
- 여러 파일의 암호화 방식이 다르면 같은 방식끼리 나눠서 처리해주세요. 비밀번호나 키도 같은 파일들끼리 처리해야 해요.
- 복사가 허용되지 않는 환경에서는 직접 복사 안내의 내용을 선택해 기기의 복사 기능을 사용해주세요.
- 다운로드가 보이지 않으면 브라우저의 다운로드 목록과 권한을 확인해주세요. 한 파일 방식의 결과는 다른 파일을 선택하거나 언어를 변경하기 전에 다시 다운로드할 수 있어요.

## 언어와 화면

설정에서 영어 또는 한국어를 선택할 수 있어요. 언어를 바꾸면 현재 입력과 결과가 지워지므로 필요한 결과를 먼저 저장해주세요. 다른 언어는 추후 추가할 수 있어요.

다크 모드는 설정에서 바꿀 수 있어요. 최초 방문 시 기기의 화면 모드 설정을 따르며, 이후 직접 선택한 모드를 기억해요.

## 기술 정보

파일 암호화는 libsodium의 XChaCha20-Poly1305, 비밀번호 키 파생은 Argon2id, 공개키 교환은 X25519를 사용해요. 기존 hat.sh v2의 파일 형식과 64 MiB 청크 형식을 유지해요.

파일의 민감한 내용이나 비밀번호·개인키를 서버로 업로드하지 않아요. 기기와 브라우저 확장 프로그램의 보안, 개인키·비밀번호의 보관은 사용 환경에 따라 달라져요.

설치와 자체 호스팅에 관한 기술 자료는 [프로젝트 저장소](https://github.com/mksdr/Veli)에서 확인할 수 있어요. 변경 기록은 아래에 원문 영어로 제공해요.
